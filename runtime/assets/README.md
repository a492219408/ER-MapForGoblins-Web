# Local generated assets

Place locally generated datasets, map tiles, icons, and text here. Only this README is tracked. The entry point is `dataset-index.v1.json`, with per-profile manifests and content-addressed resources beneath it.

Vite serves this directory at the site root and copies it into local production builds. Compose mounts it read-only for the server or optional assets service. Review generated outputs before redistribution: the source-code license does not cover game assets.

See the [setup guide](../../README.md#prepare-local-game-data).
